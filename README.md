# AI 업무 지시 정리 도구

## 프로젝트 소개
사람의 음성이나 장문의 업무 지시를 이해하기 쉬운 체크리스트로 자동 변환하는 AI 업무 정리 도구입니다.  
업무 중 상대방의 말을 한 번에 알아듣기 어렵거나 익숙하지 않은 단어가 포함된 긴 설명을 들었을 때 핵심 내용을 놓치는 불편함을 해결하기 위해 기획했습니다.

사용자가 음성 또는 텍스트로 업무 지시를 입력하면 AI가 내용을 분석하여 핵심 목표, 해야 할 일, 우선순위, 기한, 확인이 필요한 내용을 구분하고 실행 가능한 체크리스트로 정리합니다.

단순히 글을 짧게 요약하는 것이 아니라, 사람이 직접 수행하던 듣기, 이해하기, 핵심 찾기, 업무 분리하기, 순서 정하기, 메모하기 과정을 자동화하는 데 중점을 둡니다.

## 기획 배경
업무 중 다음과 같은 불편함을 반복적으로 경험했습니다.

- 상대방의 말을 정확히 듣지 못해 업무 내용을 놓치는 경우
- 익숙하지 않은 단어나 표현 때문에 지시 내용을 바로 이해하기 어려운 경우
- 장문의 업무 지시를 보고 무엇부터 해야 할지 판단하기 어려운 경우
- 여러 요청이 한 번에 전달되어 해야 할 일을 직접 다시 정리해야 하는 경우
- 기한, 우선순위, 확인 사항이 섞여 있어 중요한 내용을 놓치는 경우

이러한 불편함을 줄이기 위해 음성과 장문의 텍스트를 실행 가능한 업무 체크리스트로 변환하는 기능을 구현합니다.

## 주요 기능
### 1. 음성 업무 지시 텍스트 변환
사용자가 녹음한 업무 지시를 텍스트로 변환합니다.

### 2. 장문 업무 지시 분석
긴 업무 지시에서 핵심 목표와 실제 수행해야 할 내용을 추출합니다.

### 3. 업무 체크리스트 자동 생성
추출된 업무를 실행 가능한 단위로 나누어 체크리스트 형식으로 제공합니다.

### 4. 우선순위 및 작업 순서 정리
업무 간 선행 관계와 중요도를 분석하여 수행 순서를 제안합니다.

### 5. 기한 및 확인 사항 분리
날짜, 시간, 제출 기준, 담당자 확인 등 놓치기 쉬운 내용을 별도로 정리합니다.

### 6. 어려운 단어 설명
업무 지시에 포함된 낯선 단어나 전문 용어를 쉬운 표현으로 설명합니다.

## 서비스 동작 흐름

### 음성 입력

```text
음성 입력
→ 음성 텍스트 변환
→ 업무 내용 분석
→ 핵심 목표 추출
→ 해야 할 일 분리
→ 우선순위 및 기한 정리
→ 체크리스트 생성
```

### 텍스트 입력

```text
장문의 업무 지시 입력
→ 불필요한 설명과 핵심 내용 구분
→ 실제 수행 업무 추출
→ 작업 순서 정리
→ 기한 및 확인 사항 분리
→ 체크리스트 생성
```

## 출력 예시

```text
[핵심 목표]
MCP 서버 예외 처리 테스트 완료

[해야 할 일]
□ 허용되지 않은 Tool 호출 차단 확인
□ 잘못된 파라미터 입력 검증
□ 무한 재시도 방지 확인
□ 테스트 결과 문서 작성

[우선순위]
1. Tool 호출 차단
2. 파라미터 검증
3. 재시도 제한
4. 결과 문서 정리

[기한]
오늘 오후 5시까지

[확인이 필요한 내용]
- 제출 파일 형식
- 테스트 완료 기준

[어려운 단어]
화이트리스트: 미리 허용한 항목만 사용할 수 있도록 제한하는 방식
```

## AI 분석 항목

AI는 입력된 업무 지시에서 다음 내용을 구분합니다.

- 핵심 목표
- 실제 수행해야 할 업무
- 작업 순서
- 우선순위
- 기한
- 담당자
- 제출 대상
- 확인이 필요한 내용
- 어려운 단어
- 누락되거나 애매한 지시

## 핵심 자동화 범위
기존에는 사용자가 업무 지시를 들은 뒤 직접 다음 과정을 수행해야 했습니다.

```text
업무 지시 듣기
→ 내용 다시 기억하기
→ 핵심 찾기
→ 해야 할 일 나누기
→ 순서 정하기
→ 메모 작성하기
```

본 프로젝트는 이 과정을 다음과 같이 자동화합니다.

```text
음성 또는 텍스트 입력
→ AI 분석
→ 실행 가능한 체크리스트 자동 생성
```

## 최소 구현 범위
과제 제출을 위한 핵심 기능은 다음과 같습니다.

- 장문의 업무 지시 입력
- AI를 통한 핵심 업무 추출
- 체크리스트 자동 생성
- 우선순위 및 확인 사항 출력
