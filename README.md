# TaskLens

> 다양한 업무 자료를 AI로 분석하고 실행 가능한 업무 목록으로 정리해 주는 웹 서비스입니다.

## 1. 프로젝트 소개

업무 중에는 txt, md 등 여러 형식의 자료를 확인한 뒤 핵심 내용을 정리해야 하는 일이 자주 발생합니다.  
자료를 읽고 업무 항목을 다시 작성하는 과정에는 많은 시간이 필요합니다.

TaskLens는 업로드한 자료를 AI가 읽고 핵심 요약과 체크리스트로 변환해 주는 업무 지원 서비스입니다.  
분석 결과를 확인하는 데서 끝나지 않고 업무 상태와 알림까지 한 화면에서 관리할 수 있도록 구성했습니다.

## 2. 해결하고자 한 문제

- 문서에서 중요한 내용을 직접 찾아야 하는 불편이 있습니다.
- 문서 내용을 별도의 업무 목록으로 다시 작성해야 합니다.
- 업무 진행 상태와 예정 시간을 여러 곳에서 관리하기 어렵습니다.
- 필요한 내용을 AI와 대화하며 추가로 확인하기 어렵습니다.

## 3. 핵심 기능

- 업로드한 자료의 핵심 내용을 AI가 요약해 줍니다.
- 분석 결과를 실행 가능한 체크리스트로 정리해 줍니다.
- 체크리스트의 대기와 진행 중과 완료 상태를 변경할 수 있습니다.
- 업무 예정 시간을 등록하고 알림으로 확인할 수 있습니다.
- 분석 자료를 바탕으로 AI와 대화를 이어갈 수 있습니다.
- 최근 대화와 최근 분석 파일을 한 화면에서 확인할 수 있습니다.

## 4. 이용 흐름

1. 분석할 파일을 대화창에 첨부합니다.
2. AI에게 요약이나 분석을 요청합니다.
3. 생성된 요약과 체크리스트를 확인합니다.
4. 체크리스트의 상태와 예정 시간을 설정합니다.
5. 예약 시간이 되면 화면에 알림이 표시됩니다.

## 5. 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| Frontend | React, TypeScript, Tailwind CSS |
| Backend | Python , FastAPI |
| Database | SQLite |
| AI | Qwen 기반 대화 및 문서 분석 |

## 6. AI 활용 과정

ChatGPT를 활용해 과제 요구사항을 분석하고 기능을 작은 단위로 나누었습니다.  
화면 구성과 파일 처리 방식과 AI 응답 흐름을 차례로 구현한 뒤 실제 실행 결과를 기준으로 문제를 수정했습니다.

AI와 협업하여 파일 업로드와 긴 대화와 알림 예약 상황을 직접 검증했습니다. 파일 전송 오류와 비정상적인 AI 출력이 발생했을 때 원인을 다시 전달하고 수정 방향을 구체적으로 요청했습니다.

특히 AI가 내부 추론 출력을 막기 위해 추론 모델 자체를 끄는 방향을 제안했으나 요구사항과 맞지 않아 적용하지 않았습니다. 추론 기능은 유지하면서 사용자에게는 최종 답변만 보이도록 방향을 다시 설정했습니다.

## 7. 구현 및 검증 결과

- 사용자는 파일을 첨부하고 분석 결과를 받을 수 있습니다.
- 한글과 영어와 숫자와 특수문자가 포함된 메시지를 전송할 수 있습니다.
- 체크리스트의 상태를 변경하고 저장할 수 있습니다.
- 헤더의 알림 버튼을 누르지 않아도 예약 시간에 토스트 알림이 표시됩니다.
- 대화가 길어지면 채팅 영역에 스크롤이 생성됩니다.

## 8. 실행 방법

### Backend

```bash
poetry run uvicorn backend.app.main:app --reload
```

### Frontend

```bash
cd frontend
npm run dev
```

백엔드는 `http://127.0.0.1:8000`에서 실행됩니다. 프론트엔드는 `http://localhost:5173`에서 확인할 수 있습니다.
