# 과제 01 요약

## 📌 주요 수행 단계
- **ROS2 서비스 기초 학습**: ROS2 서비스 개념 및 서버-클라이언트 상호작용 구조 이해
- **명령행 도구 조사 및 실습**: 
  - 노드가 제공하는 서비스 목록 확인 방법
  - 서비스 호출에 필요한 정보 조회 및 호출 방법
  - `demo_nodes_cpp` 패키지의 `add_two_ints_server` 노드 실행 후 서비스 확인 및 명령행 호출 실습 (과정 별도 기록 및 정리)
- **노드 제어 및 예외 처리**: 노드 제어 프로그램이 처리되지 않은 예외 없이 정상 종료되도록 하는 방법 탐구
- **Python 기반 서비스 구현 조사**: 
  - ROS2 Python 환경에서 서비스 처리 및 타 노드 서비스 호출 방법
  - 구현에 필요한 Python 비동기 처리 방식 조사
- **실습 적용**: 기존 제어 노드 프로그램(`turtle_move_control.py`)에 서비스 서버 및 클라이언트 추가 구현
