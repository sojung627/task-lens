# 과제 01 요약: ROS2 서비스 실습

## 🎯 핵심 목표
ROS2 서비스의 서버-클라이언트 구조를 이해하고, 명령행 및 파이썬을 활용한 서비스 호출·처리 실습을 진행합니다.

## 📋 주요 수행 단계
1. **기초 학습**: ROS2 서비스 개념 및 서버/클라이언트 상호작용 구조 학습
2. **명령행 실습**: 
   - ROS2 노드의 서비스 목록 확인, 호출 정보 조회, 서비스 호출 방법 조사
   - `demo_nodes_cpp` 패키지의 `add_two_ints_server` 실행 후 제공 서비스 확인 및 명령행 호출 실습 (과정 기록 포함)
3. **노드 제어 개선**: 처리되지 않은 예외 없이 노드 제어 프로그램을 정상 종료하는 방법 연구
4. **파이썬 구현 준비**: 
   - ROS2 파이썬 프로그램에서의 서비스 처리 및 타 노드 서비스 호출 방법 조사
   - 관련 파이썬 비동기 처리 방식 학습
5. **코드 확장**: 기존 제어 노드(`turtle_move_control.py`)에 서비스 서버 및 클라이언트 기능 추가 구현
